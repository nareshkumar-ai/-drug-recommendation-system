## 2. Medicine Recommendation System Dataset (Noor Saeed)

### 2.1 Provenance & Reported Licence
* **Dataset Title:** Medicine Recommendation System Dataset
* **Curator / Author:** Noor Saeed (`noorsaeed` / GitHub: `611noorsaeed`)
* **Source URL:** [https://www.kaggle.com/datasets/noorsaeed/medicine-recommendation-system-dataset](https://www.kaggle.com/datasets/noorsaeed/medicine-recommendation-system-dataset)
* **Reported Licence:** **Apache License 2.0** (as listed in Kaggle dataset metadata)
* **Original Notices Disclosure:** The companion GitHub repository (`611noorsaeed/Medicine-Recommendation-System-Personalized-Medical-Recommendation-System-with-Machine-Learning`) does not include an explicit standalone `LICENSE` or `NOTICE` file in its root directory. However, the dataset files were publicly distributed and licensed on Kaggle under the reported Apache License 2.0.

### 2.2 Files Residing in `dataset/`
The following CSV files in this repository's `dataset/` directory originate from this dataset package:
1. `description.csv`: Textual medical definitions for 41 disease classes.
2. `precautions_df.csv`: Four actionable precautionary recommendations per disease class.
3. `medications.csv`: Recommended medication and drug category lists per disease class.
4. `diets.csv`: Dietary advice and recommended food groups per disease class.
5. `workout_df.csv`: Physical exercise and lifestyle activity recommendations per disease class.
6. `symtoms_df.csv`: Disease-to-symptom mapping table.

### 2.3 Derived Knowledge Base (`LLM Preprocessed Data.csv`)
* **Creation Pipeline:** `LLM Preprocessed Data.csv` is a derived compilation generated locally by [`prepare_data.py`](file:///c:/Users/nkpra/Projects/drug%20prediction/prepare_data.py).
* **Source Inputs:** It was created exclusively by merging the five runtime lookup tables (`description.csv`, `precautions_df.csv`, `medications.csv`, `diets.csv`, and `workout_df.csv`).
* **Transformations Applied:** Disease names were canonically normalized (handling minor typographical variances in raw tables), multi-column precautions were consolidated, workout entries were grouped by disease, and all rows were joined into exactly 41 unified disease profiles.
* **Derivative Status:** Under Section 1 of the Apache 2.0 License, `LLM Preprocessed Data.csv` represents a Derivative Work created from the five constituent tables. Its redistribution is permitted under Section 4 of Apache 2.0, subject to retaining proper attribution and license notices.

### 2.4 Cloud Vector Index Artefacts (`documents.json` and `index.faiss`)
* **Pipeline Context:** If and when cloud index files are generated by [`build_cloud_index.py`](file:///c:/Users/nkpra/Projects/drug%20prediction/build_cloud_index.py), the output files residing in `vectorstore/faiss_gemini/`:
  * `documents.json`: Contains structured text slices and metadata extracted directly from `LLM Preprocessed Data.csv`.
  * `index.faiss`: Contains dense mathematical vector representations (768-dimensional unit-normalized embeddings) generated from those text slices.
* **Licensing Obligation Notice:** Vector embeddings and serialized document slices are **not** assumed to be legally exempt from source licence obligations. Because they derive directly from the Apache 2.0-licensed knowledge base, their redistribution on public repositories or hosting environments remains subject to applicable Apache 2.0 terms (attribution, change notice, and license retention).

## 3. Disease Prediction Using Machine Learning (Kaushil Shah)

### 3.1 Provenance & Reported Licences
* **Dataset Title:** Disease Prediction Using Machine Learning
* **Curator / Author:** Kaushil Shah (`kaushil268`), derived from open clinical benchmark distributions
* **Source URL:** [https://www.kaggle.com/datasets/kaushil268/disease-prediction-using-machine-learning](https://www.kaggle.com/datasets/kaushil268/disease-prediction-using-machine-learning)
* **Reported Licences:**
  * **Database Structure / Compilation:** **Open Data Commons Open Database License (ODbL) v1.0**
  * **Database Contents:** **Open Data Commons Database Contents License (DbCL) v1.0**
  *(Reported under Kaggle badge: "Database: Open Database, Contents: Database Contents")*

### 3.2 File Residing in `dataset/`
* `dataset/Drug_Recommendation_Data.csv`: A local renamed copy of `Training.csv` from the Kaushil268 dataset.
* **Structure:** Exactly 4,920 rows $\times$ 133 columns, consisting of 132 binary symptom indicators (`itching`, `skin_rash`, etc.) and one target classification column (`prognosis`) covering 41 disease classes.

### 3.3 Applicable Conditions & Share-Alike Scope
* **Attribution (ODbL § 4.3):** Any public use or redistribution of the database, or any works produced from it, requires clear attribution to the original author (`kaushil268`) and reference to the ODbL 1.0 licence.
* **Share-Alike Scope (ODbL § 4.4):** If an *Adapted Database* is created from this dataset and publicly used or distributed, that Adapted Database must be licensed under the ODbL v1.0.
  * **Non-Inclusion in RAG Pipeline:** `LLM Preprocessed Data.csv` does **not** incorporate or adapt any data from `Drug_Recommendation_Data.csv`. Therefore, `LLM Preprocessed Data.csv` is not an Adapted Database of the Kaushil268 dataset, and ODbL share-alike conditions do not apply to it.

### 3.4 Machine Learning Model (`models/drug_gboot.pkl`)
* **Training Provenance:** The Gradient Boosting model (`models/drug_gboot.pkl`) was trained offline using the symptom-disease classification matrix in `Drug_Recommendation_Data.csv`.
* **Attribution:** Full credit is given to Kaushil Shah (`kaushil268`) as the source of the training dataset.
* **Legal Classification Status:** While models trained on databases are commonly treated as "Produced Works" under ODbL Section 4.5 (which do not require the model weights themselves to be licensed under ODbL), no unsupported definitive legal declaration is made here regarding that classification. The formal legal status of machine learning model parameters trained on ODbL-licensed data remains an evolving and unresolved legal question that has not been independently determined.
